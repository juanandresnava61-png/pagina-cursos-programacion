Programador Front-end

En este programa vas a aprender a transformar una idea en una experiencia web clara, atractiva y fácil de usar.

Qué vas a aprender

  • HTML y CSS
  • JavaScript
  • Diseño responsive y accesibilidad
  • Integración con APIs
  • Git y publicación de proyectos

Ideal para vos si...

Te interesa el diseño, la creatividad y querés crear páginas que funcionen correctamente en computadoras, tablets y celulares.

Programador Full-Stack

Vas a recorrer todo el proceso de desarrollo de una aplicación, desde la interfaz que ve el usuario hasta la información que procesa el servidor.

Qué vas a aprender

  • Front-end y back-end
  • Bases de datos relacionales y no relacionales
  • APIs y autenticación
  • Buenas prácticas y control de versiones
  • Despliegue de aplicaciones

Ideal para vos si...

Querés tener una visión completa de un producto digital y desarrollar proyectos funcionales de principio a fin.
